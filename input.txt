Using winget tool
Install winget tool if you don't already have it, then type this command in command prompt or Powershell.

Note: The package in winget is not maintained by the Git for Windows project and might deviate from the latest official version. winget install --id Git.Git -e --source wingetGit.Git

Using Chocolatey
Install Chocolatey if you don't already have it, then run:

Note: The package in Chocolatey is not maintained by the Git for Windows project and might deviate from the latest official version. choco install gitgit

The current source code release is version 2.56.0. If you want the newer version, you can build it from the source code.
